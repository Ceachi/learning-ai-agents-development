# learning-ai-agents-development

Repo for learning AI agents development. Each folder is a separate course:

- **[skillab-ai-agent-development](skillab-ai-agent-development/)** — the Skillab AI agents course: lessons plus homeworks (ReAct agents, RAG, LangGraph multi-agent, memory/caching, MCP & guardrails).
- **[Google workshop multiagent](Google%20workshop%20multiagent/)** — Google workshop on the Agent Development Kit (ADK): building, deploying (Agent Engine) and evaluating multi-agent systems (module PDFs).
